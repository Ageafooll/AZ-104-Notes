
**Azure DNS** lets us host out DNS records for our domain on globall distributed Azure infrastructure which gives you security features like RBAC, activity logs, resource locking etc., it acts as the SOA (start of authority) for the domain. (you don't use it to register a domain name, you need a domain registrar or using App Service Domains)

A **DNS zone** is a specific, managable section of a DNS name space. A zone can be another zones child to delegate. Different zones have different databases.

Azure DNS is a global resource, you don't worry about regions.
You can configure a **public** or **private DNS zone**.

When creating a **public DNS zone** we assume you already own the domain and delegating the queries to Azure's name servers with **NS records**. It is visible to internet. You don't have to prove you own the domain you just change the NS records via your **registrar** to point to provided servers:

**Private zones** provide name resolution for VMs within a linked virtual network. It is not visible to internet so you don't need to register the domain. You link it with virtual networks (not limited to one VNet) to allow name resolution with that zone. You configure it during or after creation of the private dns zone:
![[Pasted image 20260813124342.png|617]]

You don't have to change any NSGs in a VNet to allow private zones name resolution. It is implicitly allowed to communicate with Azures platform without requiring outbound or inbound port 53 rules.

Azure DNS supports **alias record sets** which points to an Azure resource, you just choose the resource when creating the record and even though when underlying ip address of the resource changes you won't have to do a change in the record itself. It can be used for **public IP address**, **Traffic Manager profile**, **front-door profile** etc.
It helps to **prevent dangling DNS records** too.

**Apex domain** is our domains highest level, in our case in public zone it is "bruhmomentum.com". The "@" symbol in name of the record represents the **apex domain**.
