
It is a command-line shell and a scripting language by Microsoft.

This module will only talk about basics.

Key concepts are **objects**, **cmdlets** and **pipeline**.

Commands are called **cmdlets** and use a readable Verb-Noun pattern, like:
```
Get-Process
Stop-Service
```

It is **Object-Oriented** so its outputs aren't plain text like bash, it passes .NET objects.
```
(Get-Process).Id
```

**The Pipeline ( | )** Allows us to take the output object of one command as an input to another command

**Comparison** is done with operators like -eq, -gt not with >, ==
```
Get-Process | Where-Object Id -eq 1

#("Get-Process -Id 1" does the same thing better but im just tryna show the pipeline) 
```

It allows you to use bash commands like cat, cd etc.. too

Stream operators like "**>**" works like in bash, it's an alias for **Out-File**

```
Write-Output "bruh" > bruh.txt
# equals to
Write-Output "bruh" | Out-File bruh.txt

Get-Process -Name "WrongName" 2>> errors.txt
```

Variables have $ sign before it and referenced with it

```
$date = Get-Date
Write-Host $date
```

An commands output object is referenced with "$\_" after pipeline
ForEach-Object is a for loop built specifically for the pipeline
```
Get-Process | Where-Object Id -gt 1000 | ForEach-Object { $_.ProcessName}
```

**Wildcards** works in similar way with bash

```
Get-Command -Name "Get-*"
or
Get-Command | Where-Object { $_.Name -like "Get-*" }
```

Simple **Loops** can be done in this ways:
```
for ($i = 1; $i -le 5; $i++) { Write-Host "Attempt number: $i" }

$retryCount = 0 
while ($retryCount -lt 3) { Write-Host "Retrying connection..."; $retryCount++ }
```

**If**, **else** are like this
```
if($in -eq 21)
{
	Write-Host "bruh"
}
else
{
	Write-Host "whatever"
}
```
