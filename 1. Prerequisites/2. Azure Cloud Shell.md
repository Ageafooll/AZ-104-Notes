
It's a command-line environment in web browser. 

It has the most recent version of PowerShell or Bash which gives you access to most recent versions of Azure CLI and Azure PowerShell. And it has add-ons preconfigured:  AzCopy, git, npm, vim, Kubectl, MySQL client, Terraform, Ansible, code ... 

You can persist files (might be scripts you constantly use for operations) on Cloud Shell by using cloud drive (can be accessed out of cloud shell too its a storage account you manage) which also lets you access them in a different device (different sessions) you can upload local files at the top bar. It is mounted at $HOME directory automatically. You can also mount a Azure File Share from Azure Files. You need to configure the storage account initially to persist files.

You should not use this if you:
- Wanna leave the session open for more than 20 mins for long running scripts (it terminates session).
- Need sudo access. (you can't)
- Install unsupported tools directly.
- Need storage from different regions (compute container and storage account is in same data center).
